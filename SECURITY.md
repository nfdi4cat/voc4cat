# Security policy

## Reporting a vulnerability

Report security vulnerabilities in the template, including its GitHub Actions workflows, privately through GitHub's private vulnerability reporting:
<https://github.com/nfdi4cat/voc4cat-template/security/advisories/new>

Do not open a public issue for a vulnerability.
The maintainers acknowledge a report within 5 working days and keep you informed until it is resolved.

Report vulnerabilities in the conversion tool to [voc4cat-tool](https://github.com/nfdi4cat/voc4cat-tool/security/advisories/new).

## Supported versions

Fixes are made on the `main` branch and published with the next template release.
Repositories created from the template do not receive fixes automatically; their maintainers apply them from the release notes.
